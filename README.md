# Operating_System_Lab
lab programs, algorithms
📚 Algorithms Included
✅ First Come First Serve (FCFS)
✅ Shortest Job First (SJF)
✅ Priority Scheduling
✅ Round Robin (RR)

📌 Implemented Programs
1. FCFS (First Come First Serve)
Non-preemptive scheduling
Processes execute in the order they arrive
Simple and easy to implement

2. SJF (Shortest Job First)
Non-preemptive scheduling
Selects the process with the shortest burst time
Minimizes average waiting time

3. Priority Scheduling
Executes processes based on priority
Supports priority-based execution
Lower priority number indicates higher priority (implementation dependent)

4. Round Robin
Preemptive scheduling algorithm
Uses a fixed Time Quantum
Ensures fairness among processes
